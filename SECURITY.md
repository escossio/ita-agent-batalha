# Segurança

Não publique credenciais, dados de clientes, dumps ou detalhes privados em issues/PRs.
Para vulnerabilidades, use o canal privado de security advisories do GitHub quando disponível; não inclua segredos em descrição pública.

Regras e limites em `docs/security/SECURITY_BOUNDARIES.md`; riscos em `docs/security/THREAT_MODEL.md`.
O material HTML em docs/source é referência arquivada, não aplicação hospedada.
Não existem APIs bancárias reais nem movimentação financeira nesta fundação.
